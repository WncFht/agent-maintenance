# Crossnote 验证

本页说明预览资源的检查入口、行为覆盖和目标环境验收边界。仓库测试验证当前源码与生成物；工作区的调研、原型、截图和历史结果在仓外保存，不作为构建依赖。一次旧验收通过不能证明新版本或另一种输入设备已通过。

## 自动化入口

在维护仓中安装锁定依赖后运行：

```sh
node assets/.crossnote/scripts/build.cjs --check
npm run test:preview
```

测试不会自动构建来掩盖生成物漂移；需要更新产物时先运行 `npm run build:preview`。首次准备浏览器使用 `npx playwright install chromium`，Linux CI 使用 `--with-deps`。

| 验证面     | 主要证据                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| 构建与解析 | 完整生成器漂移检查、真实 QuickJS、伪代码选项、编号、错误恢复、vendor 校验                                  |
| 外观与图表 | Mermaid 11.15.0／12.2.0 的五类图、六种纸张、系统／编辑器主题、作者配色与打印；切换颜色不改 SVG 几何        |
| 独立导出   | SVG／HTML 标签、字体嵌入、SVG 与 PNG、资源不可读取时的失败提示                                             |
| 查看器     | [diagram-viewer.test.cjs](diagram-viewer.test.cjs) 覆盖下表中的导航、选择、输入与生命周期行为              |
| 部署       | [sync.test.cjs](sync.test.cjs) 覆盖副本、只读检查、旧部署迁移、定制保护、锁和失败回滚                      |
| 宿主输出   | [crossnote-export.test.cjs](crossnote-export.test.cjs) 使用 Crossnote 0.9.42 验证离线 HTML 与 Chromium PDF |

浏览器测试按实际计算颜色、文本、几何、独立文档和下载结果判断，不以“渲染未报错”替代结果。声明支持的图种以[资源说明](../README.md)为准。

## 查看器回归

| 场景           | 必须保持的行为                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 正文入口       | 单击图表打开；拖动、链接与作者回调保留原行为；关闭后恢复入口焦点                                 |
| 平移与捏合     | 双轴自由移动，方向键按图片方向移动；连续缩放与事件拆包不改变预期倍率，CSS zoom 下焦点稳定        |
| 宿主路由       | MPE 的 document 捕获模型不能抢走画布缩放；关闭后释放监听；倍率菜单内的修饰键滚轮不缩放整篇文档   |
| 惯性与生命周期 | 原生惯性和旧内核降级有明确归属；失焦、取消、关闭或移除后不粘滞、不重复响应                       |
| 倍率与尺寸     | 预设和自定义输入正确，非法输入不改变倍率；fit 跟随尺寸，手动模式保留图中中心                     |
| 节点选择       | 两套 Mermaid 的五类图可命中；拖动不误选；ID／marker 引用隔离，浮动工具不改变视口或原图           |
| 小地图         | 默认收起、按需加载、位于左下；视口框与主图一致，图外可找回，拖动保留抓取偏移并正确清理           |
| 界面与关闭     | 无常驻提示、空选择文字和选中项定位；查看器双击不缩放；Esc 先收起已打开的倍率菜单，否则关闭查看器 |
| 样式兼容       | 注入旧查看器 CSS 后仍无第二份原生滚动位置；图形与画布同底色，浅色、深色及作者背景保持一致        |

## 目标环境验收

浏览器合成事件和 Crossnote HTML 输出不替代真实 webview 的资源、CSP 与键盘路由验证。部署到测试项目，信任工作区，在用户设置启用预览脚本，并设置 `previewTheme: none.css` 与 `previewColorScheme: systemColorScheme`。关闭并重新打开整个 MPE 预览页后，检查：

1. 正文单击打开、作者链接保留、主题与原生配色退出正常。
2. 触控板平移／捏合、倍率输入和全图只改变图表；窗口变化后视图符合当前模式。
3. 节点高亮、复制、清除与小地图正确，画布尺寸不因选择变化。
4. 倍率菜单与 Esc 的关闭顺序、关闭重开后的状态和焦点正确。
5. SVG／PNG 实际下载成功，打印隐藏交互控件。

Mac 实机还需覆盖双指甩动后按 ⌘、平移与捏合立即互换、切出应用再返回、Retina／外接屏和系统辅助缩放。Linux Chromium 或 code-server 的成功不代表 Mac 物理触控板手感、高刷新率帧率、Safari 或触摸屏已验收。

`bench-profile.cjs` 是伪代码钩子性能分析入口，不是发布门控；`--deps`／`BENCH_DEPS` 指向分析环境，`--corpus` 提供文档，`--repeat` 控制重复次数。历史性能数值只有在版本和实验条件仍相符时才能作为证据。
