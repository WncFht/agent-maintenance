# 文档篇幅与检查边界

篇幅用于提醒归属和阅读成本，不证明内容质量。不做重复检测，不用统一行数截断理论推导、实验报告或完整参考。

`scripts/doc-policy.json` 声明 `hard_limits`：路径到最大非空白字符数。计数包含 Markdown、代码和表格，排除空白，方便中英文混合内容复核；不是英文词数，也不是 token 数。只为反复读取的 AGENTS、skill 入口等常驻文件设置硬上限。不存在的预算文件、非正整数或超限阻断检查。新增上限保留合理余量；提高上限先说明为何归位或精简不足，不能自动按当前长度放宽。

同一配置的 `soft_limits` 用 glob 选择需要观察的页面并给出字符阈值。超限只打印提示，不阻断，也不授权拆分或删字。项目可为研究报告保留大篇幅，重点检查一个实验或章节是否混入其他问题。预算清单是上限的唯一事实源，正文不复制逐文件数值。

处理顺序：先迁出不属于该页的内容，再删除无信息重复和执行流水；保留约束、失败、负结果、推导与复现条件。仍需更多空间时按项目审阅流程修改硬预算。冻结历史与第三方内容不参加演进预算。

文档检查验证本地目标与 Markdown 标题锚点，包括页内链接、中文、重复标题、代码标题及显式 HTML id/name；目录链接有片段时解析其 README。归档出链不修复，活动页面链接进归档仍检查。非 Markdown 产物的 fragment、外部链接、公式语义和自然语言结论不由本检查判断。复杂数学标题优先使用稳定的显式锚点。

检查器根据目标文档解析锚点；标题变更必须修复入链。只增加链接却继续维护两份完整说明仍是内容归属问题，由文档审阅处理。
