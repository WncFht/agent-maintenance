# 文档分工与事实核验

| 载体             | 权威内容                                       | 避免放入                             |
| ---------------- | ---------------------------------------------- | ------------------------------------ |
| 根 AGENTS.md     | 每次任务持续需要的短规则和入口                 | 长例子、事故过程、情景操作说明       |
| 子目录 AGENTS.md | 该区域特有的要求                               | 重复父层规则                         |
| 架构说明         | 组合、职责、关键链路和扩展点                   | 全部类型、每包实现清单               |
| 模块 README      | 配置、语义、失败、限制、扩展与消费者影响       | 其他模块的说明、JSDoc 和生成目录重复 |
| 接口注释         | 调用点必须知道的条件、返回、失败、顺序与所有权 | 长历史与重复架构推导                 |
| 教程             | 前提、按序动作、可观察成功与恢复               | 穷尽接口清单                         |
| 参考             | 主题范围内可检索的当前语义                     | 无关主题与教学流水                   |
| Agent Notes      | 决策理由、替代方案、代价与验证                 | 局部任务记录和过期实施计划           |
| 事故报告         | 时序、证据、因果、影响和预防                   | 无因果价值的实现展开                 |
| 生成参考         | 可从源码或元数据确定的清单                     | 人工并行维护                         |
| 工作记录         | 假设、测量和未决事项                           | 未标明的当前承诺                     |

一项事实一个归属，其他位置引用。调用点必须完整的安全条件可以局部重复；不能为了去重让使用者漏读取消、所有权和失败后果。

页面先确定位置和主题，再确定详细程度与类型。教程按前提和难度组织；参考按查询问题组织。上层只介绍直接子项的职责，细节链接到下层。很长的混合形式拆开，小段混合明确标识。

操作断言应按最终展示方式执行：安装、命令、配置、默认行为及失败场景。记录实际观察；不能运行时保留必要说明，但明确缺少的环境、待验证断言及负责验证的人或检查，不伪造通过。

命令、路径、配置键与默认值不从邻包类推。来源更新后再生成目录、例子和快照。移动文件同时修复入链。文档格式检查不能证明行为正确。

对常驻入口测量上下文和查询成本，对穷尽参考测量检索单元与最大章节。先归位和删除重复，再论证预算；不采用全仓统一删字比例，也不把英文词数直接转为中文阈值。
