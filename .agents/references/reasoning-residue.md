# 清理会话残留

先遵循 [maintain-prose](../skills/maintain-prose/SKILL.md) 的范围、授权、排除项和完整命题原则。

判据：只有当前 HEAD、没有会话、PR 对话或未提交草稿的读者，是否能解析每个引用并核验事实。不能时重述有效事实，再移除会话叙述；没有事实的控制流旁白直接删除。

分类寻找：失效设计编号与阶段标签；下一层 PR 或上一提交的视角；当前文档中的旧新变更流水；审阅轮次和谁同意了什么；向 reviewer 证明自己正确的辩解；代码逐行翻译；实施后残留的计划和猜测。

明确保留：有解析目标的 issue 和抑制理由；真实旧新兼容契约；标准章节；事故时序；决策备选和有证据的限制。能解析只是合格的必要条件，当前状态页面仍应把历史故事归位。

先只读检索，使用[搜索与反例](prose-examples.md)校准真阳性和近似反例。范围包括被默认忽略的自有隐藏目录；第三方和 archived 除外。探针不定义违规，继续无模式阅读密集文字，避免把零命中当完成。

来源优先修复，再更新所有派生物；可见字符串按行为验证。删前检查是否改变义务、把假设升级为已实现、删去事实或证据。重跑探针、检查引用、阅读完整 diff，报告保留与延后项。
