# AGENTS.md — 冻结历史

封存记录不得修改、格式化、移动或删除，不作为当前行为权威。日常审计跳过其正文与出链，仍可有意识地引用它的历史理由。

一次封存仅允许移动已实施记录、在 Status 行下增加 Archived: YYYY-MM-DD，并修复入链。单语记录和在清单中明确列出的附件分别封存，不自动推断其他语言或附件。

先核对封存 diff，再从仓库根执行：

```sh
python3 scripts/notes_guard.py --root . --seal
python3 scripts/notes_guard.py --root . --base <可信目标分支提交>
```

--seal 只为新增归档项追加哈希，不移动文件，不更新已存在哈希。当前清单不防止与正文同时重写；CI 必须用可信事件或目标分支确定 --base，取到对应历史且不能让 PR 自选基线。禁止从未经核实的 PR 环境值直接提供该参数。
