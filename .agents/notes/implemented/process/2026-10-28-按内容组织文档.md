# Agent Note: 按内容组织文档

Status: implemented

固定实验层级和正文模板会把短任务扩成填空式报告。写作辅助改为按需清单，实验记录只约束证据与结论的联系，Notes 正文允许自由组织；机器检查保留状态、非空正文、路径和归档完整性。实际规则见[实验记录](../../../references/experiment-reports.md)与[决策记录](../../../references/decision-notes.md)。

保留固定模板作为默认入口仍会引导机械填节，因此删除实验、参考和决策模板；完全删除证据规则则会丢失复现与未完成状态的约束。这里选择保留内容要求，取消章节强制。内容是否充分仍由审阅判断，检查通过不能证明决定已有充分理由。

此决定部分取代[文档归属与实验交付](2026-10-19-文档归属与实验交付.md)中的模板做法；原有事实归属、锚点和篇幅预算继续适用。验证覆盖自由正文、自选标题、错误状态、空正文与冻结历史改写。
