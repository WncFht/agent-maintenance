# Agent Note: 维护包收缩到文档与决策记录

Status: implemented

## 问题

原维护包包含通用审阅、验证选择、源码规则与性能基准规则，超过当前所需的文档维护范围。只删除技能入口会留下没有使用入口的专项方法，并使保留清单失真。

## 决策

只保留 maintain-docs、maintain-prose、maintain-decision-notes 三个技能，删除 packages、benchmarks、审阅和验证选择技能，以及其资源生命周期、失败处理、可靠测试、测试诊断、性能、简化、Agent 接口与审阅反馈参考。保留文档与 Notes 使用的共享规范、模板和工具链。

此决定取代[原维护包决定](2026-10-15-portable-maintenance-pipeline.md)中的五技能集合和源码、基准目录安排；原决定中的暂存快照、CI 和归档保护仍然适用。

工具链接入现由[工具链接入决定](2026-10-17-工具链接入与暂存格式化.md)部分扩展；三个技能和产品方法边界继续有效。

## 考虑过的替代方案

只隐藏两个技能而保留全部专项参考，可以减少删除量，但仍需维护与当前用途无关的资料。把全部验证设施一起移除会失去链接、技能结构、Notes 和冻结历史的可执行保护，因此保留维护包自己的检查、hooks 与 CI。

## 后果

技能集合检查同步为三个，README 与来源说明只列当前保留内容。维护包不再提供通用代码审阅或产品验证方法；目标项目继续使用自己的开发规范。未纳入内容需查阅上游来源，三个技能仍共享相对路径布局，迁移时须保留其引用资源。
