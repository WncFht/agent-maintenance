# Agent Note: Crossnote 自由画布与查看器样式归属

Status: implemented

## 问题

按图片尺寸约束平移，会在图片较小时强制居中，也会阻止把边缘内容移动到想看的位置。独立查看器需要自由画布的操作方式。原本先清除选择、再次 Esc 才退出的行为也不符合直接关闭查看器的预期。

查看器脚本按需加载，文档样式由 MPE 单独加载和缓存。新版 transform 控制器如果混用旧版 overflow 滚动样式，会同时产生原生滚动位置和相机偏移，破坏可见边界与命中。只在完整新版 CSS 下测试无法发现这种组合。

## 决策

平移不限制在图形边缘，缩放始终保留光标对应的图中位置；全图按钮负责找回并居中。允许图形完全离开视口，不增加自动吸回或第二份滚动状态。Esc 在倍率菜单打开时先收起菜单，其余情况直接关闭；清除选择保留独立按钮和空白点击。

查看器布局源码仍在 styles 目录维护，但构建到同一个延迟加载的图表操作模块。打开时插入带组件属性范围的 CSS，显式重置旧版视口高度、外边距和 overflow，关闭时一起清理。页面主题变量继续继承，文档与图表配色不另建状态。

单选使用可见的蓝色外框与浅底；选中后出现的浮动操作区不占布局空间，选中节点不触发画布缩小和重新适配。节点适配覆盖流程图、状态图、类图、ER 实体与时序参与者；真实指针点击、仅有 click 的激活和键盘选择都进入同一选择逻辑，拖拽后的 click 被抑制。

本记录部分取代[图表视口交互](2026-10-25-Crossnote图表视口交互.md)的图形边界限制；触控板优先、唯一相机、事件归属和快照隔离保持有效。使用说明归 [Crossnote README](../../../../assets/.crossnote/README.md)。

## 考虑过的替代方案

- 扩大可移动边距仍会形成新的停止点，不能满足自由移动的要求。
- 只要求用户刷新样式，无法防止下一次脚本和宿主样式分别更新。查看器几何由组件共同交付，不依赖宿主的独立样式刷新时机。
- Shadow DOM 可进一步隔离第三方 CSS，但会增加既有焦点、事件路径与宿主固定元素缩放的适配；当前采用限定范围的组件样式，并测试旧规则叠加。

## 后果

移动后可能看不到图形，工具栏保持固定可用，全图是明确恢复入口。选择范围仍需逐图种验证，不能泛化到所有 Mermaid 元素。自动化覆盖自由移动、视口外缩放、找回、旧样式叠加、两套 Mermaid 的五类图点击和一次退出，入口见[验证说明](../../../../assets/.crossnote/tests/README.md)。Mac 物理触控板与宿主键盘路由仍需实机验收，浏览器事件测试不替代该证据。
